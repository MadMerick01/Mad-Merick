# Mad Merick

A hardcore post-apocalyptic trucking game for BeamNG.drive, set across the real Australian outback on BeamNG.Earth. Start in a rust-bucket fuel tanker near Adelaide, take fuel, ammo and parts from marauders and other tankers, and make it 1,500 km north to Pine Gap.

Nothing is built yet. See [docs/DESIGN.md](docs/DESIGN.md) for the design.
